Job Market Data Analysis

Comprehensive analysis of tech skills, job roles, and hiring demand

Project Overview

This project analyzes job market trends to identify key technical skills, top hiring roles, and location-based job distributions. The analysis combines data cleaning, SQL query analysis, Python visualizations, and Power BI dashboards to extract actionable insights.

Technologies Used:

SQL Python (Pandas, Matplotlib) Power BI Excel HTML / CSS

Key Findings & Insights

  • High Demand Skills: SQL, Python, and Excel remain the top required skills across Data Analyst and Business Analyst postings.
  • Work Mode Distribution: On-site and Hybrid roles dominate over fully Remote positions.
  • Top Roles: Data Analyst, Business Analyst, and Business Intelligence Analyst show maximum open hiring positions.

Sample SQL Analysis

Example query used to aggregate top skills from job postings data:


SELECT skill_name, COUNT(job_id) AS total_postings
FROM job_skills
GROUP BY skill_name
ORDER BY total_postings DESC
LIMIT 10;
